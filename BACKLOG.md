# Беклог

- [x] **Portfolio · мобільна версія.** На першій картці заголовок «Indywidualne» має поміщатися в один рядок ліворуч від кнопки «Zobacz galerię», як на скриншоті від 18.11.2026 о 23:16. При ширині 390 px перевірити, що слово видно повністю, а між заголовком і кнопкою є відступ.
- [ ] **Контактна форма · Telegram.** Прибрати інтеграцію з FormSubmit. Надсилати заявки безпосередньо з браузера через Telegram Bot API (`sendMessage`). Для обфускації зберігати токен бота та ID каналу як фрагменти Base64 і збирати їх перед запитом. Повні значення будуть видимі в мережевому запиті. Використовувати бота з мінімальними правами для публікації в заданому каналі. Перевірити з опублікованого сайту, що заявка з усіма полями з’являється в каналі, а форма показує успіх лише після підтвердження від Telegram.

  - Вимагати один контакт для відповіді: коректний номер телефону або коректну адресу електронної пошти. Порожнє поле чи некоректне значення блокують надсилання й показують помилку біля поля.
  - Надсилати повідомлення з `parse_mode: "HTML"` та екранувати введені користувачем значення. Готове повідомлення в Telegram має містити не більше 512 видимих символів разом із підписами полів. Якщо ліміт перевищено, показати помилку у формі й дати скоротити текст.
  - Реалізація готова. Форму перевірено в Chrome з імітацією відповіді Telegram, а право бота публікувати підтверджено через API. Залишилась тестова заявка з опублікованого сайту.

  ```json
  {
    "chatId": ["LTEwMDQ0MT", "UzNjAzMjc="],
    "botToken": ["OTI4NTcyNTQzODpBQUZoQW45M3JYLS1v", "NjF4LVI0cGZDUVBtZklRVFFkc1IwSQ=="]
  }
  ```
